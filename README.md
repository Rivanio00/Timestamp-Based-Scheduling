# Como rodar

OBS.: É necessário ter o C# e o .NET instalado em sua máquina para rodar

1. Coloque o arquivo de entrada na pasta media como "in.txt";
2. Builde o código
```bash
dotnet build 
```
3. Rode o projeto
```bash
dotnet run
```

As saídas dos objetos estão na pasta dados e a saída dos escalonamentos na pasta media como "out.txt"
